# Adding swagger documentation

When changing the parameters or endpoints of the API, please update the swagger documentation in [swagger.json](./swagger.json) at the repo root. It is served publicly at https://api.uniswap.org/v2/uniswapx/docs.

[test/unit/swagger.test.ts](./test/unit/swagger.test.ts) pins the swagger to the joi schemas that validate requests and responses (query params, chain ids, order types, statuses, entity fields, error codes). If you change either side, the test tells you exactly what is out of sync:

```
yarn jest test/unit/swagger.test.ts
```

To edit the swagger visually:

1. Visit the open source [editor](https://editor.swagger.io/)
2. Copy and paste the contents of [swagger.json](./swagger.json)
3. The editor will ask you to transform the file into yaml, click yes
4. Make your changes and make sure the swagger is valid. The editor warns if it is not
5. Click on `File`, then `Convert and save as json` and update the [swagger.json](./swagger.json) file
6. Run the drift test above; CI also validates the file with `rdme openapi:validate`
